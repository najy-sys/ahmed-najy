# News Banner Studio — استوديو البنرات الإخبارية

تطبيق ويب عربي بواجهة RTL لإنشاء بنرات إخبارية احترافية جاهزة لمنصات التواصل الاجتماعي. يركز التطبيق على قالب بصري ثابت عالي التباين، ومعاينة حية، ولوحة تحكم سهلة للعنوان، الصورة، الشارة، الشعار، القوالب، المقاسات، المكتبة، والتصدير.

## التشغيل

```bash
npm run dev
```

ثم افتح `http://localhost:5173`.

## الفحص

```bash
npm run build
```

يتحقق الأمر من صحة ملف JavaScript الرئيسي عبر `node --check`.
